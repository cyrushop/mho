旅人配裝器

魔物獵人：旅人 · 五屬性最強配裝同升級素材

1武器

2等級

3目標技能

等級留空＝盡量疊高。優先度：高 ×3、中 ×2、低 ×1。套裝技能嘅「等級」＝要達到第幾段門檻。

4選項

防具庫

標記「已有」：計素材時唔再計呢件；揀咗「同分優先已有」就會優先用。標記「排除」：配裝唔會用。

數據狀態

匯入數據

支援 JSON（完整數據庫）或 CSV（防具表）。檔案只存喺呢部機嘅瀏覽器。

數據格式

CSV 欄位

name,set,part,rarity,defense,skills,set_skill,materials

  • part：head/chest/arms/waist/legs（或 頭/胸/腕/腰/腳）
  • skills、materials：名:數量; 名:數量（亦接受 名 x2）
  • set_skill：呢件計入邊個套裝技能（件數門檻要喺 JSON 嘅 setSkills 定義）
JSON 結構 
{
  "meta": { "updated": "YYYY-MM-DD", "sources": ["網址"] },
  "arCaps": [ { "ar": 16, "rarity": 3 } ],
  "skills": [ { "name": "技能", "maxLevel": 5 } ],
  "setSkills": [ { "name": "套裝技能",
    "tiers": [ { "pieces": 2, "effect": "效果" } ] } ],
  "weapons": [ { "name": "武器", "type": "long-sword",
    "rarity": 5, "skills": { "技能": 1 } } ],
  "armor": [ { "id": "唯一id", "name": "名", "set": "套裝",
    "part": "head", "rarity": 5, "defense": 40,
    "skills": { "技能": 2 }, "setSkill": "套裝技能",
    "materials": { "素材": 2 },
    "upgrades": [ { "toRarity": 6, "materials": { "素材": 1 } } ] } ]
}
